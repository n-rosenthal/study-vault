* Visão Geral: Do Anel Booleano aos Polinômios Gerais $R[x]$ (Lang, Cap. IV)
No estudo anterior, construímos o anel booleano livre $\mathcal{B}_n \cong \mathbb{F}_2[x_0, \dots, x_{n-1}]/(x_i^2 - x_i)$. Agora abandonamos as relações de idempotência ($x^2 = x$) e a restrição de característica $2$ para estudar o **anel de polinômios em uma indeterminada $x$** sobre um anel comutativo arbitrário $R$ (Lang, Capítulo IV, §1–§2):

$$R[x] = \left\{ \sum_{i=0}^{d} a_i x^i \;\middle|\; a_i \in R,\; d \in \mathbb{N} \right\}.$$

Quando o anel de coeficientes é um **corpo** $K$ (como $\mathbb{Q}$ ou $\mathbb{F}_p$), $K[x]$ torna-se um **Domínio Euclidiano** munido da função de grau $\deg : K[x] \setminus \{0\} \to \mathbb{N}$. Neste documento:
1. **Formalizamos em Lean 4** a estrutura de corpo (~Field~), a representação de polinômios como listas densas normalizadas e provamos a **existência da divisão euclidiana** em $K[x]$.
2. **Implementamos em Rust** o corpo primo $\mathbb{F}_p$ (~Fp<const P: u64>~), o anel genérico de polinômios ~Poly<R>~ e o **Algoritmo de Euclides Estendido** para calcular $\gcd(f, g)$ e coeficientes de Bézout em $K[x]$.

** Hierarquia Algébrica: Do Anel Comutativo ao Corpo ($K$)
Para realizar a divisão de polinômios $f(x) = q(x)g(x) + r(x)$, precisamos inverter o coeficiente líder de $g(x)$ (Lang, Cap. IV, Teorema 1.1). Portanto, estendemos ~CommRing~ (definido em ~BooleanRingDuality.lean~) para ~Field~:

#+begin_src lean4
import BooleanRingDuality

namespace StrangeAlgebras.Polynomials

open StrangeAlgebras.BooleanDuality

/-- Capítulo II, §1 (Lang): Corpo (Field) como anel comutativo onde 1 ≠ 0
    e todo elemento não-nulo possui inverso multiplicativo -/
class Field (K : Type u) extends CommRing K where
  inv : K → K
  zero_ne_one : zero ≠ one
  mul_inv_cancel : ∀ {a : K}, a ≠ zero → mul a (inv a) = one

/-- Operação de divisão em um corpo: a / b = a * b⁻¹ -/
def div {K : Type u} [Field K] (a b : K) : K :=
  CommRing.mul a (Field.inv b)
#+end_src

** Representação Densa de Polinômios e Operações Básicas
Representamos um polinômio $p(x) = a_0 + a_1 x + \dots + a_d x^d$ como uma lista de coeficientes `[a₀, a₁, ..., a_d]` (do termo constante para o termo de maior grau). Para garantir unicidade de representação, definimos a função de normalização ~normalize~ que remove zeros à direita (*trailing zeros*).

#+begin_src lean4
/-- Polinômio representado por lista de coeficientes [a₀, a₁, ..., a_d] -/
abbrev Poly (R : Type u) := List R

section PolyOps
variable {R : Type u} [CommRing R] [DecidableEq R]

/-- Remove zeros supérfluos no topo do polinômio (canonicalização) -/
def normalize : Poly R → Poly R
  | [] => []
  | a :: as =>
    match normalize as with
    | [] => if a = CommRing.zero then [] else [a]
    | bs => a :: bs

/-- Adição de polinômios termo a termo -/
def polyAdd : Poly R → Poly R → Poly R
  | [], q => q
  | p, [] => p
  | a :: as, b :: bs => CommRing.add a b :: polyAdd as bs

/-- Multiplicação por escalar c · p(x) -/
def scale (c : R) : Poly R → Poly R
  | [] => []
  | a :: as => CommRing.mul c a :: scale c as

/-- Multiplicação por x^k (deslocamento à direita de k zeros) -/
def shift (k : Nat) (p : Poly R) : Poly R :=
  List.replicate k CommRing.zero ++ p

/-- Multiplicação de polinômios (convolução de Cauchy):
    (a + x·p) * q = a·q + x·(p * q) -/
def polyMul : Poly R → Poly R → Poly R
  | [], _ => []
  | a :: as, q => polyAdd (scale a q) (shift 1 (polyMul as q))

/-- Grau formal (comprimento da lista normalizada menos 1; 0 para o polinômio nulo) -/
def natDegree (p : Poly R) : Nat :=
  (normalize p).length - 1

end PolyOps
#+end_src

** Teorema da Divisão Euclidiana em $K[x]$ (Lang, Cap. IV, §1)

*** Prova Matemática (LaTeX)
*Teorema 1.1 (Algoritmo da Divisão em $K[x]$).* Seja $K$ um corpo e sejam $f, g \in K[x]$ com $g \neq 0$. Existem únicos polinômios $q, r \in K[x]$ tais que
$$f = q \cdot g + r \qquad \text{com } r = 0 \text{ ou } \deg(r) < \deg(g).$$

/Demonstração (Existência por indução forte sobre $\deg(f)$)./
- *Caso Base:* Se $f = 0$ ou $\deg(f) < \deg(g)$, tomamos $q = 0$ e $r = f$, satisfazendo $f = 0 \cdot g + f$ imediatamente.
- *Passo Indutivo:* Suponha $\deg(f) = n \ge m = \deg(g)$, com termos líderes $a_n x^n$ ($a_n \neq 0$) e $b_m x^m$ ($b_m \neq 0$). Como $K$ é um corpo, existe $b_m^{-1} \in K$. Definimos o termo quociente $t(x) = (a_n b_m^{-1}) x^{n - m}$ e o polinômio reduzido
  $$f_1(x) = f(x) - t(x) \cdot g(x).$$
  Por construção, o coeficiente de $x^n$ em $f_1(x)$ é $a_n - (a_n b_m^{-1}) b_m = a_n - a_n = 0$, logo $f_1 = 0$ ou $\deg(f_1) < n$. Pela hipótese de indução aplicada a $f_1$, existem $q_1, r \in K[x]$ com $f_1 = q_1 g + r$ e $r = 0$ ou $\deg(r) < m$. Substituindo $f_1$:
  $$f = (t + q_1) g + r,$$
  concluindo a existência com $q = t + q_1$. $\blacksquare$

*** Implementação da Redução Euclidiana e Prova do Passo em Lean 4
Abaixo implementamos o passo de redução euclidiana (~euclidStep~) e provamos formalmente o **Lema da Anulação do Termo Líder**, que justifica a terminação e correção do algoritmo:

#+begin_src lean4
section EuclideanDivision
variable {K : Type u} [Field K] [DecidableEq K]

/-- Lema algébrico: em um corpo K, a - (a * b⁻¹) * b = 0 para b ≠ 0 -/
theorem cancel_leading_coeff (a b : K) (hb : b ≠ CommRing.zero) :
    CommRing.add a (CommRing.neg (CommRing.mul (div a b) b)) = CommRing.zero := by
  unfold div
  calc CommRing.add a (CommRing.neg (CommRing.mul (CommRing.mul a (Field.inv b)) b))
    _ = CommRing.add a (CommRing.neg (CommRing.mul a (CommRing.mul (Field.inv b) b))) := by
        rw [CommRing.mul_assoc]
    _ = CommRing.add a (CommRing.neg (CommRing.mul a (CommRing.mul b (Field.inv b)))) := by
        rw [CommRing.mul_comm (Field.inv b) b]
    _ = CommRing.add a (CommRing.neg (CommRing.mul a CommRing.one)) := by
        rw [Field.mul_inv_cancel hb]
    _ = CommRing.add a (CommRing.neg (CommRing.mul CommRing.one a)) := by
        rw [CommRing.mul_comm a CommRing.one]
    _ = CommRing.add a (CommRing.neg a) := by
        rw [CommRing.one_mul]
    _ = CommRing.add (CommRing.neg a) a := by
        rw [CommRing.add_comm]
    _ = CommRing.zero := CommRing.neg_add a

/-- Subtração de polinômios: p - q = p + (-1)·q -/
def polySub (p q : Poly K) : Poly K :=
  polyAdd p (scale (CommRing.neg CommRing.one) q)

/-- Um passo da divisão longa: reduz o termo líder de `f` usando o divisor `g` -/
def euclidStep (f g : Poly K) : Poly K × Poly K :=
  let fn := normalize f
  let gn := normalize g
  if gn.isEmpty || fn.length < gn.length then
    ([], fn)
  else
    let degDiff := fn.length - gn.length
    let leadF := fn.getLastD CommRing.zero
    let leadG := gn.getLastD CommRing.zero
    let factor := div leadF leadG
    let term := shift degDiff [factor]
    let rem := normalize (polySub fn (polyMul term gn))
    (term, rem)

end EuclideanDivision
end StrangeAlgebras.Polynomials
#+end_src

No Rust, traduzimos a hierarquia `Ring` $\rightarrow$ `Field` via *traits* e implementamos:
1. **`Fp<const P: u64>`:** O corpo finito primo $\mathbb{Z}/p\mathbb{Z}$ (com inversão modular via exponenciação binária $a^{p-2} \bmod p$ pelo Pequeno Teorema de Fermat).
2. **`Poly<R>`:** Polinômios densos normalizados sobre qualquer `Ring`, com divisão euclidiana `div_rem` e **Algoritmo de Euclides Estendido (`extended_gcd`)** restritos via `where K: Field` (exatamente como no teorema do Lang!).

#+begin_src rust
use std::fmt;

/// Capítulo II, §1 (Lang): Trait computacional para Anel Comutativo com Unidade
pub trait Ring: Clone + PartialEq + fmt::Debug + fmt::Display {
    fn zero() -> Self;
    fn one() -> Self;
    fn is_zero(&self) -> bool {
        self == &Self::zero()
    }
    fn add(&self, other: &Self) -> Self;
    fn neg(&self) -> Self;
    fn sub(&self, other: &Self) -> Self {
        self.add(&other.neg())
    }
    fn mul(&self, other: &Self) -> Self;
}

/// Capítulo II, §1 (Lang): Trait computacional para Corpo (Field)
pub trait Field: Ring {
    fn inv(&self) -> Option<Self>;
    fn div(&self, other: &Self) -> Option<Self> {
        other.inv().map(|inv_b| self.mul(&inv_b))
    }
}

/// Corpo Primo F_p = Z / pZ (requer P primo)
#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub struct Fp<const P: u64>(pub u64);

impl<const P: u64> Fp<P> {
    pub fn new(val: i128) -> Self {
        let m = P as i128;
        let rem = ((val % m) + m) % m;
        Self(rem as u64)
    }

    pub fn pow(&self, mut exp: u64) -> Self {
        let mut base = *self;
        let mut acc = Self::one();
        while exp > 0 {
            if exp & 1 == 1 {
                acc = acc.mul(&base);
            }
            base = base.mul(&base);
            exp >>= 1;
        }
        acc
    }
}

impl<const P: u64> fmt::Display for Fp<P> {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        write!(f, "{}", self.0)
    }
}

impl<const P: u64> Ring for Fp<P> {
    fn zero() -> Self {
        Self(0)
    }
    fn one() -> Self {
        Self(1 % P)
    }
    fn add(&self, other: &Self) -> Self {
        Self(((self.0 as u128 + other.0 as u128) % P as u128) as u64)
    }
    fn neg(&self) -> Self {
        if self.0 == 0 {
            Self(0)
        } else {
            Self(P - self.0)
        }
    }
    fn mul(&self, other: &Self) -> Self {
        Self(((self.0 as u128 * other.0 as u128) % P as u128) as u64)
    }
}

impl<const P: u64> Field for Fp<P> {
    /// Inverso multiplicativo via Pequeno Teorema de Fermat: a^(P-2) mod P
    fn inv(&self) -> Option<Self> {
        if self.is_zero() {
            None
        } else {
            Some(self.pow(P - 2))
        }
    }
}

/// Capítulo IV, §1 (Lang): Anel de Polinômios Univariados R[x]
/// Coeficientes armazenados em ordem crescente de grau: coeffs[i] * x^i
#[derive(Clone, PartialEq, Eq, Debug)]
pub struct Poly<R: Ring> {
    pub coeffs: Vec<R>,
}

impl<R: Ring> Poly<R> {
    pub fn new(mut coeffs: Vec<R>) -> Self {
        while coeffs.last().map_or(false, |c| c.is_zero()) {
            coeffs.pop();
        }
        Self { coeffs }
    }

    pub fn zero() -> Self {
        Self { coeffs: Vec::new() }
    }

    pub fn one() -> Self {
        Self::new(vec![R::one()])
    }

    pub fn is_zero(&self) -> bool {
        self.coeffs.is_empty()
    }

    /// Grau do polinômio (None para o polinômio nulo)
    pub fn degree(&self) -> Option<usize> {
        if self.is_zero() {
            None
        } else {
            Some(self.coeffs.len() - 1)
        }
    }

    pub fn leading_coeff(&self) -> Option<&R> {
        self.coeffs.last()
    }

    pub fn add(&self, other: &Self) -> Self {
        let len = self.coeffs.len().max(other.coeffs.len());
        let mut res = Vec::with_capacity(len);
        for i in 0..len {
            let a = self.coeffs.get(i).cloned().unwrap_or_else(R::zero);
            let b = other.coeffs.get(i).cloned().unwrap_or_else(R::zero);
            res.push(a.add(&b));
        }
        Self::new(res)
    }

    pub fn sub(&self, other: &Self) -> Self {
        let len = self.coeffs.len().max(other.coeffs.len());
        let mut res = Vec::with_capacity(len);
        for i in 0..len {
            let a = self.coeffs.get(i).cloned().unwrap_or_else(R::zero);
            let b = other.coeffs.get(i).cloned().unwrap_or_else(R::zero);
            res.push(a.sub(&b));
        }
        Self::new(res)
    }

    pub fn mul(&self, other: &Self) -> Self {
        if self.is_zero() || other.is_zero() {
            return Self::zero();
        }
        let mut res = vec![R::zero(); self.coeffs.len() + other.coeffs.len() - 1];
        for (i, a) in self.coeffs.iter().enumerate() {
            for (j, b) in other.coeffs.iter().enumerate() {
                res[i + j] = res[i + j].add(&a.mul(b));
            }
        }
        Self::new(res)
    }

    /// Multiplica por c * x^deg_shift
    pub fn monomial_mul(&self, coeff: &R, deg_shift: usize) -> Self {
        if self.is_zero() || coeff.is_zero() {
            return Self::zero();
        }
        let mut res = vec![R::zero(); deg_shift];
        for c in &self.coeffs {
            res.push(c.mul(coeff));
        }
        Self::new(res)
    }

    /// Avaliação de Horner: p(x_0)
    pub fn eval(&self, x: &R) -> R {
        self.coeffs
            .iter()
            .rev()
            .fold(R::zero(), |acc, c| acc.mul(x).add(c))
    }
}

/// Operações exclusivas para K[x] quando K é um Corpo (Domínio Euclidiano)
impl<K: Field> Poly<K> {
    /// Normaliza o polinômio tornando-o mônico (coeficiente líder = 1)
    pub fn make_monic(&self) -> Self {
        match self.leading_coeff().and_then(|lc| lc.inv()) {
            Some(inv_lc) => self.monomial_mul(&inv_lc, 0),
            None => Self::zero(),
        }
    }

    /// Teorema da Divisão Euclidiana: retorna (q, r) tal que self = q * divisor + r
    /// com r = 0 ou deg(r) < deg(divisor).
    pub fn div_rem(&self, divisor: &Self) -> Option<(Self, Self)> {
        if divisor.is_zero() {
            return None;
        }
        let mut rem = self.clone();
        let mut quot = Self::zero();
        let deg_d = divisor.degree().unwrap();
        let inv_lead_d = divisor.leading_coeff().unwrap().inv().unwrap();

        while let Some(deg_r) = rem.degree() {
            if deg_r < deg_d {
                break;
            }
            let diff = deg_r - deg_d;
            let factor = rem.leading_coeff().unwrap().mul(&inv_lead_d);
            let term = Self::new(vec![factor.clone()]).monomial_mul(&K::one(), diff);
            quot = quot.add(&term);
            rem = rem.sub(&divisor.monomial_mul(&factor, diff));
        }

        Some((quot, rem))
    }

    /// Algoritmo de Euclides Estendido em K[x]:
    /// Retorna (g, u, v) onde g é mônico e u * self + v * other = g = gcd(self, other).
    pub fn extended_gcd(&self, other: &Self) -> (Self, Self, Self) {
        let (mut r0, mut r1) = (self.clone(), other.clone());
        let (mut u0, mut u1) = (Self::one(), Self::zero());
        let (mut v0, mut v1) = (Self::zero(), Self::one());

        while !r1.is_zero() {
            let (q, r2) = r0.div_rem(&r1).unwrap();
            let u2 = u0.sub(&q.mul(&u1));
            let v2 = v0.sub(&q.mul(&v1));

            r0 = r1;
            r1 = r2;
            u0 = u1;
            u1 = u2;
            v0 = v1;
            v1 = v2;
        }

        // Normaliza para que o MDC seja mônico (único em K[x])
        match r0.leading_coeff().and_then(|lc| lc.inv()) {
            Some(inv_lc) => (
                r0.monomial_mul(&inv_lc, 0),
                u0.monomial_mul(&inv_lc, 0),
                v0.monomial_mul(&inv_lc, 0),
            ),
            None => (Self::zero(), Self::zero(), Self::zero()),
        }
    }
}

impl<R: Ring> fmt::Display for Poly<R> {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        if self.is_zero() {
            return write!(f, "0");
        }
        let mut parts = Vec::new();
        for (i, c) in self.coeffs.iter().enumerate() {
            if c.is_zero() {
                continue;
            }
            let term = match i {
                0 => format!("{}", c),
                1 => format!("{}x", c),
                _ => format!("{}x^{}", c, i),
            };
            parts.push(term);
        }
        write!(f, "{}", parts.join(" + "))
    }
}

* Próximo Passo: Anéis Quocientes $K[x]/(f(x))$ e Corpos Finitos $\mathbb{F}_{p^n}$ (Lang, Cap. V)
Com `div_rem` e `extended_gcd` operacionais em $K[x]$, temos todas as peças para construir **extensões algébricas simples** e **corpos finitos** $\mathbb{F}_{p^n} \cong \mathbb{F}_p[x]/(f(x))$ (onde $f$ é irredutível de grau $n$):
1. A multiplicação no quociente $K[x]/(f(x))$ é simplesmente `(a.mul(&b)).div_rem(&f).1`.
2. A inversão de qualquer elemento não-nulo $a(x) \notin (f(x))$ é dada diretamente pelo coeficiente de Bézout $u(x)$ retornado por `a.extended_gcd(&f)`, já que $\gcd(a, f) = 1 \implies u(x)a(x) + v(x)f(x) = 1 \implies u(x) \equiv a(x)^{-1} \pmod{f(x)}$.
